Problématique
  • Multiplication des cyberattaques : brute force, injections SQL, scanners offensifs, anomalies géographiques — les organisations font face à des menaces de plus en plus diversifiées.
  • Logs dispersés : dans une architecture distribuée, les traces d'attaques sont éparpillées entre plusieurs services, rendant la corrélation et l'analyse difficiles.
  • Détection réactive : sans monitoring centralisé, les incidents sont détectés trop tard, augmentant l'impact sur les systèmes.
  • Besoin d'une approche proactive : centraliser, analyser et alerter en temps réel est devenu indispensable pour toute infrastructure moderne.

Présentation du projet
SecureWatch
Plateforme de Surveillance de Sécurité

SecureWatch est une plateforme de surveillance de sécurité en temps réel, développée dans le cadre du PFA 2025-2026. Elle centralise la collecte des logs, détecte automatiquement les incidents de sécurité et génère des alertes en temps réel dans une architecture microservices conteneurisée.

Menaces & types d'attaques ciblés

Brute Force
≥5 tentatives de connexion échouées depuis la même IP → détection CRITIQUE

Injection SQL
Regex sur les champs de login, blocage 400 + log SQL_INJECTION

Scanners Offensifs
Détection via User-Agent (sqlmap, Nikto, Nessus, masscan, gobuster…)

Anomalie Géographique
Requêtes depuis IP de pays à risque (RU, CN, KP, IR, TOR, NG)

Accès Non Autorisés
Réponses 401/403 agrégées et détectées par Logstash

Dépassement de Débit
Rate limiting Nginx (5r/m auth, 30r/m API, 100r/m global) → 429

Besoins fonctionnels
  • Collecter et centraliser les logs de sécurité de tous les services via Filebeat → Logstash → Elasticsearch
  • Détecter automatiquement les incidents de sécurité en temps réel : brute force, injection SQL, scanners offensifs, anomalies géographiques, rate limiting violations (10 event_types)
  • Générer et envoyer des alertes automatiques via Prometheus + Alertmanager (11 règles d'alerte) avec webhook vers le dashboard
  • Afficher un dashboard SPA en temps réel avec SSE, statistiques, graphiques (Chart.js), carte géographique (D3.js)
  • Authentifier les utilisateurs via JWT HS256 et gérer les accès par rôle (Admin, Operator, User)
  • Simuler des 9 scénarios d'attaque automatisés pour les tests et démonstrations

Besoins non-fonctionnels
  • Sécurité : TLS/HTTPS avec certificats auto-signés, chiffrement JWT HS256, rate limiting 3 zones Nginx, prévention des injections de logs via sanitize_input()
  • Performance : traitement des logs en temps réel, alertes SSE push sans polling, réponse dashboard < 1s
  • Disponibilité : 14 conteneurs Docker orchestrés avec health checks, Redis pour la persistance des alertes (survie aux redémarrages)
  • Scalabilité : architecture microservices indépendante, chaque service peut être mis à l'échelle séparément
  • Maintenabilité : pipeline Logstash configurable, règles d'alerte Prometheus externalisées, documentation complète (rapport LaTeX + README)
  • Observabilité : métriques Prometheus exposées par chaque service, dashboards Grafana infrastructure + sécurité, index ILM Elasticsearch
